# 手机CPE 0.11.1 / code33

2026-11-24 公开测试版，支持从此前同签名版本覆盖升级。新增蜂窝物理载波与网络 AMBR 信息，修复独立 ROOT 进程电话服务初始化缺失导致已插 SIM 仍显示无 SIM 的问题。

## 更新内容

- 主屏顶部显示 LTE/NR 服务载波数量与网络下发 AMBR，速率统一 M/s；实时上下行大字布局保持。MCPE 设置增加蜂窝网络详情，展示主/辅载波、频段、带宽、AMBR 类型和无法读取原因。
- LTE+NR 双连接与各自的载波聚合数量分别表达；相同制式/频点去重。切换数据 SIM、制式或互联网连接后清理旧 AMBR，过期或无法确认归属的数据不显示。
- ROOT 物理信道回调根据当前系统 ABI 注册。AMBR 仅对受支持 MTK 辅助 AT 通道执行有时限的只读查询，要求独占、SIM 和唯一默认互联网上下文均可确认；不修改基带绑定，不扫描未知端口。
- 在独立 ROOT 进程中补齐模块化电话服务管理器，已有实例不重复初始化；旧系统无此类时沿用原路径。蜂窝采集继续使用独立 ROOT 会话，不阻塞共享协调。
- Release 保持 R8 优化、混淆和资源压缩，保留 ROOT 与现代 Xposed 入口，沿用现有证书。

## 最终验证

- 132 项核心测试；Debug/Release 构建和 lint 通过（0 errors / 40 warnings）；最终 APK 签名、DEX 入口与混淆检查通过。
- 一加 9R / Android 14 真实完成自身 ROOT 更新器 32→33；安装 APK 摘要一致，前台服务恢复、偏好和 system_server 保持。
- 应用与独立 ROOT 会话均收到 NR 物理载波；长按 MCPE 详情和主屏显示相符。Wi-Fi→蜂窝→Wi-Fi 上游切换时热点持续开启，结束后原 Wi-Fi 重新关联且系统验证通过。
- 强停后原 ROOT 进程全部退出，重开后 SIM/NR 回调、前台守护和热点状态恢复，无遗留 ROOT 会话。

## 适配边界

- 一加 9R 系统只报告一个 NR 服务载波，并未提供频段、带宽或有效频点；对应字段显示 —。本轮未实际验证多载波聚合、多 SIM 切换、MTK 基带通道或真实 AMBR。
- 当前 AMBR 通道不支持 Qualcomm。一加 9R 切到活跃蜂窝互联网连接后返回 UNSUPPORTED；显示的 AMBR 是网络下发上限，不等同于套餐宣传速率或测速。
- Android 9+ 需要 ROOT；原生以太网共享需 Android 11+ 及系统/网卡驱动支持。其他 ROM、Find X9 Pro 上的新蜂窝采集和 Android 9–13 等环境仍需实机验收。既有共享/VPN/框架守护的验证边界继续适用。
- 未在本轮重启手机或追加新版 LSP 注入验收；已启用模块的用户需重启后才会加载新模块代码。
