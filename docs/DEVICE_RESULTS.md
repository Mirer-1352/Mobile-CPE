# OnePlus 8T 实测记录

日期：2026-11-20。只操作本次连接的 OnePlus 8T / KB2000，另一台 OPD2404 未安装或修改。设备上报 Android 17 / API 37，Magisk 31.1。安装版本 0.3.0（versionCode 3）。本记录仅代表该机，不代表所有 ROM 和 Android 版本。

## 已验证

| 项目 | 结果与证据 |
| --- | --- |
| 安装升级 | 从设备上的 0.1.0 原位升级至 0.3.0，保留共享意图与默认桌面配置 |
| 界面调整 | Wi-Fi、USB、以太网三个开关均位于设置首屏；首页只有实际共享摘要、连接数量、共享方式设置入口及守护按钮 |
| 运营商与无线状态 | 实际显示 CMCC、5G SA、实时信号等级与 dBm，随射频状态变化 |
| Root 通道 | 修复 PATH 中没有 su 的情形，通过 /debug_ramdisk/su 启动独立 Root 进程；在 Magisk 界面仅为本应用授予权限后成功连接 |

| USB 外网 | curl 显式绑定 USB 网卡的 IPv4 地址，访问 https://www.baidu.com/robots.txt，HTTP 200，2814 bytes；确认流量通过手机 USB 转发，而非电脑原有网卡 |
| USB 恢复 | 外部 stop USB 导致接口撤销及 ADB 短暂断开，守护重开后 rndis0、ADB 和界面均恢复 |

| 开机恢复 | 临时启用开机选项，ADB 重启设备；boot_id 改变后，在未手动启动应用的情况下观察到 HotspotService 前台运行、wlan2 恢复共享、蜂窝上游 rmnet_data2 |
| 桌面 | 设备原先已经将本应用设为默认 HOME；升级与重启后保持原配置 |
| 构建验证 | assembleDebug、lintDebug 通过；直接 JUnit 入口 12 项测试通过；调试 APK 签名校验通过 |

## 修复

- 共享开关迁入设置，首页保留状态摘要。
- 增加 /debug_ramdisk/su 等常见绝对路径兼容；没有改动 Root 管理器的全局策略。
- Root 子进程异常退出时保留少量输出作为错误诊断。
- 窄手机屏幕的上下行速率改为适当宽度下并排显示。
- 面板与设置分开保存滚动位置；系统返回键可从设置回面板。
- 固定浅色界面的深色状态栏图标，改善对比度。
- 排除 /sys/class/net 中不是目录的 bonding_masters 文件。

- USB 恢复测试采用系统实际停止/重启共享与 USB 重新枚举，没有进行人工拔线重插。
- 未连接无线客户端，未测试 Wi-Fi 多客户端统计、其他 Android 版本、双卡切换和长时间息屏稳定性。
